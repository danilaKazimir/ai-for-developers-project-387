# Календарь звонков

Сервис, в котором один организатор предлагает разные форматы встреч,
а гости по ссылке на событие выбирают свободное время в его общем календаре.

## Термины

**Организатор**:
Человек, с которым гости записываются на встречи через общий календарь.
_Avoid_: Создатель календаря.

**Календарь**:
Общее расписание и занятость одного организатора, используемые всеми его событиями.
_Avoid_: Независимый календарь типа события.

**Событие (тип события)**:
Формат встречи с названием, описанием и длительностью, которым организатор делится с гостями по постоянной ссылке.
_Avoid_: Календарь, слот, бронирование, предстоящая встреча.

**Гость**:
Человек, который выбирает свободное время для встречи с организатором по ссылке на событие.

**Каталог**:
Публичный список событий организатора.

**Слот**:
Возможность записаться на встречу выбранного формата с определёнными началом и окончанием.
_Avoid_: Бронирование.

**Бронирование**:
Подтверждённая встреча, занимающая время в общем календаре организатора.
_Avoid_: Слот.

**Предстоящая встреча**:
Бронирование, начало которого ещё не наступило или совпадает с текущим моментом.

**Страница записи**:
Самостоятельная публичная страница конкретного события, на которой гость по полученной ссылке выбирает время и подтверждает встречу.
