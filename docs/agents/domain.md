# Domain docs

## Перед исследованием кода

В этом репозитории используется single-context:

- Читай `GLOSSARY.md` в корне: это общий словарь предметной области.
- В `docs/adr/` читай решения, относящиеся к исследуемой области.

Если этих файлов ещё нет, продолжай работу без уведомлений об их отсутствии
и предложений создать их заранее. Навык `domain-modeling` создаёт словарь
и ADR по мере согласования терминов и решений.

## Расположение

- `GLOSSARY.md` — общий словарь сервиса «Календарь звонков».
- `docs/adr/NNNN-краткое-название.md` — архитектурные решения.

## Терминология

В задачах, предложениях, гипотезах и именах тестов используй термины
из словаря. Если нужного понятия нет, проверь, соответствует ли оно языку
проекта; реальный пробел отметь для `domain-modeling`.

## Противоречия решениям

Если предложение противоречит существующему ADR, явно укажи номер решения
и причину, по которой предлагаешь его пересмотреть.
