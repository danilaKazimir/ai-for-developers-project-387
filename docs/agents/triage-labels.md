# Triage labels

Соответствие канонических ролей меткам GitHub Issues:

| Роль | Метка в трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется первичный разбор |
| `needs-info` | `needs-info` | Ожидается дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова для автономного агента |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполнена |

Когда навык называет роль, используй метку из второго столбца.
Для изменения словаря редактируй второй столбец.
