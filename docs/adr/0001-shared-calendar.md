# Один календарь для всех событий

Одна установка обслуживает одного организатора. События задают разные форматы и длительности, а любое бронирование занимает время в общем календаре. Поэтому встреча одного формата скрывает пересекающееся свободное время у всех форматов, а предстоящие встречи можно показать единым списком.
