---
name: implement-spec
description: Выполни согласованную спецификацию и её тикеты по прямой команде implement-spec в исходном GitHub issue.
---

1. Найди в исходном issue подтверждённую спецификацию и перечисленные в команде тикеты. Прочитай их через `gh issue view`. Если согласование или объём работы неясны, укажи, чего не хватает, в ответе к issue.
2. Реализуй критерии в предоставленной рабочей ветке. Добавь приёмочные тесты, запусти проверки по области изменения и `mise run lint`. Зафиксируй результат каждой проверки.
3. Сделай локальный Conventional Commit. В теле добавь отдельную строку `Refs #N` для тикета реализации. Проверь чистоту рабочего дерева. Оставь публикацию ветки и открытие PR обработчику OpenCode.
4. В финальном ответе заполни разделы из `.github/pull_request_template.md`. Включи критерии приёмки, исходное issue, спецификацию, тикеты и проверяемые результаты. Опиши последствия ошибки и конкретный способ отката.
